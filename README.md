# realme C55 — промо-страница

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Не требует сервера,
сборки, зависимостей или базы данных.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него `index.html`, `style.css`,
   `script.js` и `README.md`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. После публикации страница появится по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Шрифты загружаются из Google Fonts; при недоступности сервиса используются
системные шрифты. Иллюстрации смартфона созданы средствами CSS.
